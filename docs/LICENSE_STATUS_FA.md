# وضعیت لایسنس لورانیک 1.0.0

این سند فقط وضعیت اثبات‌شده فعلی را ثبت می‌کند و جایگزین دستور رسمی راست‌چین نیست.

## نتیجه فعلی

- محصول لورانیک یک قالب مدیریتی React / Next.js است، نه قالب/افزونه WordPress.
- صفحات جاری محصولات مدیریت HTML در راست‌چین مدل‌های لایسنس عادی و ویژه را نمایش می‌دهند.
- راهنمای ویدیویی لایسنس موجود در منابع پروژه عمدتاً جریان PHP/WordPress و محیط‌های مرتبط با RSM را نشان می‌دهد.
- از منابع بررسی‌شده، روش رسمی و مشخصی برای افزودن فعال‌سازی RSM به سورس React/Next.js اثبات نشده است.

## تصمیم فنی

در نسخه `1.0.0` هیچ سیستم فعال‌سازی، تماس API یا قفل دامنه ساختگی به سورس اضافه نمی‌شود.

این تصمیم برای جلوگیری از موارد زیر است:
- اختلال در نصب و Build خریدار
- وابستگی غیرمستند به API یا سرویس خارجی
- پیاده‌سازی امنیتی شکننده در کد Front-end
- تعارض احتمالی با روش رسمی راست‌چین

## Gate قبل از ارسال

اگر پنل فروشنده برای دسته انتخاب‌شده فقط انتخاب نوع لایسنس فروش را می‌خواهد، همان گزینه رسمی پنل استفاده شود.

اگر پنل صراحتاً «لایسنس‌گذاری فنی/RSM» را برای این محصول React/Next.js الزام کرد، قبل از تغییر سورس باید از پشتیبانی فروشندگان راست‌چین روش رسمی مخصوص این نوع محصول دریافت شود.

تا آن زمان عبارت «لایسنس RSM در سورس پیاده‌سازی شده» نباید در صفحه فروش یا مستندات محصول استفاده شود.
