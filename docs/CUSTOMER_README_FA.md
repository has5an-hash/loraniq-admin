# لورانیک ادمین 1.0.0 — راهنمای خریدار

لورانیک یک قالب رابط کاربری مدیریتی فارسی و راست‌چین مبتنی بر React، Next.js و TypeScript است. داده‌های نمایش‌داده‌شده در داشبوردها نمونه هستند و برای نمایش رابط کاربری استفاده می‌شوند.

## پیش‌نیازها

- Node.js نسخه `22.13.0` یا جدیدتر
- npm

## نصب و اجرا

در پوشه اصلی پروژه اجرا کنید:

```bash
npm ci
npm run dev
```

پیش‌نمایش توسعه به‌صورت پیش‌فرض روی پورت `5173` اجرا می‌شود.

برای کنترل کد و ساخت نسخه production:

```bash
npm run lint
npm run typecheck
npm run build
```

برای اجرای Build ساخته‌شده در محیط محلی:

```bash
npm run start
```

## مسیرهای دموی نسخه فعلی

- `/demo/commerce` — تجارت
- `/demo/analytics` — تحلیل داده
- `/demo/projects` — مدیریت پروژه
- `/demo/finance` — امور مالی
- `/demo/crm` — مدیریت مشتریان
- `/demo/academy` — آکادمی
- `/demo/calendar` — تقویم
- `/demo/inbox` — پیام‌ها
- `/demo/components` — کامپوننت‌ها
- `/demo/settings` — تنظیمات

## شخصی‌سازی

فایل‌های اصلی ظاهر و صفحات:

- `app/page.tsx` — لندینگ
- `app/globals.css` — استایل عمومی لندینگ
- `app/demo/[slug]/admin-demo.tsx` — رابط و محتوای دموهای مدیریتی
- `app/demo/[slug]/dashboard.css` — استایل داشبوردها و Responsive
- `app/layout.tsx` — متادیتا و تنظیمات پایه سند

رنگ اصلی فعلی `#7367F0` است. سند اصلی با زبان فارسی و جهت RTL رندر می‌شود.

## نکات توسعه

لورانیک یک قالب Front-end/React است و به‌تنهایی Backend تجاری، احراز هویت سازمانی یا API کسب‌وکار شما را فراهم نمی‌کند. برای استفاده در پروژه واقعی، داده‌های نمونه را به API یا منبع داده پروژه خودتان متصل کنید.

پوشه `components/ui/` شامل مجموعه‌ای از کامپوننت‌های رابط قابل استفاده مجدد است. مجوزهای وابستگی‌های شخص ثالث در `docs/THIRD_PARTY_LICENSES.txt` آمده است.
