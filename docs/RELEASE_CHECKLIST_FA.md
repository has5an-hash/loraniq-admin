- [x] لندینگ فارسی و RTL
- [x] ۱۰ مسیر دموی مدیریتی تعریف‌شده
- [x] تجارت و تحلیل داده
- [x] مدیریت پروژه
- [x] مالی، CRM و آکادمی
- [x] تقویم، پیام‌ها، کامپوننت‌ها و تنظیمات

- [x] راهنمای نصب و شخصی‌سازی فارسی
- [x] حذف ادعاهای اثبات‌نشده مثل «۱۲ دمو»، «۱۲۰+ صفحه» و امتیاز ساختگی

## راست‌چین / Marketplace

مرجع داخلی پروژه از مقاله رسمی راست‌چین با آخرین بروزرسانی ثبت‌شده ۰۹ تیر ۱۴۰۵ می‌گوید متن و تصاویر نهایی محصول نباید خروجی AI باشند؛ معرفی ۲ خط، ۵ ویژگی اصلی و اینفوگرافیک ۹۶۰px و زیر ۱MB از الزامات ثبت‌شده‌اند.

بنابراین فایل‌های قدیمی `marketing/` و `docs/RTL_THEME_LISTING_FA.md` تا زمان بازبینی انسانی **خروجی قابل ارسال به مارکت محسوب نمی‌شوند**.

- [ ] متن نهایی صفحه محصول توسط انسان و مطابق ساختار جاری راست‌چین آماده/تأیید شده است
- [ ] معرفی دقیقاً ۲ خط است
- [ ] دقیقاً ۵ ویژگی اصلی، هرکدام یک خط
- [ ] فهرست کامل ویژگی‌ها فقط شامل عنوان‌هاست
- [ ] اینفوگرافیک نهایی ۹۶۰px و زیر ۱MB است
- [ ] کاور/اینفوگرافیک نهایی دارای منشأ و طراحی مجاز و بدون ردپای AI است
- [ ] لینک پیش‌نمایش واقعی محصول ثبت شده است
- [ ] شرایط پشتیبانی، نام فروشنده و اطلاعات لازم مارکت نهایی شده است
- [ ] وضعیت لایسنس برای محصول HTML/Next.js بر اساس روش رسمی مورد تأیید راست‌چین مشخص شده است
