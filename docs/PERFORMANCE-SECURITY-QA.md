# Performance & Security QA

This gate measures the shipped static export and audits the dependency graph before a release can be marked ready.

## Static performance budget

Generated by `scripts/qa-performance.mjs` after the production static build.

Hard release budgets:
- complete static export: <= 40 MB
- all JavaScript chunks combined: <= 10 MB
- largest JavaScript chunk: <= 800 KB
- all CSS combined: <= 2 MB
- largest CSS file: <= 500 KB
- largest image: <= 1.5 MB
- largest font file: <= 1 MB
- six dashboard demo previews combined: <= 6 MB

The JSON report is stored at `artifacts/performance/static-budget-report.json`. The report also records the 30 largest exported files so regressions can be traced instead of hidden.

These are release safety budgets, not a claim that every route downloads the full totals. Route-level runtime performance still requires representative browser profiling and manual review.

## Dependency security audit

CI runs two blocking audits:
1. production dependencies: block high/critical advisories
2. complete dependency graph: block critical advisories

Audit console output is mirrored into `artifacts/security/`.

A passing package-manager audit does not prove application security. Static template release review still includes secret/credential checks, external-request review, auth-claim accuracy and manual source inspection.

## Competitor quality reference

Metronic explicitly documents performance-oriented modern Next.js architecture and publishes dependency security updates; Vuexy positions itself as a scalable, high-performance and customizable admin product. Loraniq uses those properties as quality benchmarks, without copying proprietary implementation or assets.
