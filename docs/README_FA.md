# راهنمای لورانیک — نسخه 1.0.0

لورانیک یک رابط مدیریتی فارسی و راست‌چین مبتنی بر React، Next.js و TypeScript است. نسخه انتشار فعلی `1.0.0` است.

## اجرای پروژه

1. Node.js نسخه 22.13 یا جدیدتر را نصب کنید.
2. در پوشه پروژه دستور `npm ci` را اجرا کنید.
3. برای توسعه از `npm run dev` استفاده کنید.
4. برای کنترل کامل نسخه از `npm run check` استفاده کنید.
5. برای Build نهایی به‌صورت جداگانه از `npm run build` استفاده کنید.

## مسیرهای محصول

- `/` — لندینگ معرفی محصول
- `/demo/commerce` — داشبورد تجارت
- `/demo/analytics` — تحلیل داده
- `/demo/projects` — مدیریت پروژه‌ها
- `/demo/finance` — امور مالی
- `/demo/crm` — مدیریت مشتریان
- `/demo/academy` — آکادمی
- `/demo/calendar` — تقویم و برنامه‌ریزی
- `/demo/inbox` — پیام‌ها
- `/demo/components` — کتابخانه کامپوننت‌ها
- `/demo/settings` — تنظیمات حساب

نسخه فعلی در مجموع ۱۰ فضای کاری/مسیر دموی تعاملی دارد.

## شخصی‌سازی

رنگ‌ها، سطوح، کنتراست و فاصله‌ها در `app/globals.css` و `app/demo/[slug]/dashboard.css` تعریف شده‌اند. رنگ اصلی فعلی `#7367F0` است. ریشه سند با `lang="fa"` و `dir="rtl"` رندر می‌شود.

## کنترل کیفیت

```bash
npm run lint
npm run typecheck
npm run check:release
npm run build
```

آخرین نسخه قابل تحویل باید از GitHub Actions ساخته شود تا Smoke Test مسیرها، QA مرورگری، بسته‌بندی تمیز، checksum و build manifest هم ثبت شوند.

## دارایی‌های مارکت

پوشه `marketing/` در نسخه مرجع فقط راهنمای وضعیت دارایی‌های مارکت را نگه می‌دارد و **کاور یا اینفوگرافیک نهایی داخل ریپو وجود ندارد**. دارایی نهایی صفحه فروش باید جداگانه، توسط طراح انسانی و مطابق قوانین جاری راست‌چین آماده شود. وضعیت این بخش در `docs/RELEASE_CHECKLIST_FA.md` ثبت می‌شود.

## مجوزها

فایل `LICENSES.md` توضیح می‌دهد که کتابخانه‌های شخص ثالث تحت مجوز خودشان باقی می‌مانند. پیش از انتشار، گزارش مجوز وابستگی‌های همان Build باید بررسی شود.
