# راهنمای لورانیک — نسخه 1.0.0

لورانیک یک رابط مدیریتی فارسی و راست‌چین مبتنی بر Next.js، React و TypeScript است. نسخه محصول به‌صورت دائمی روی `1.0.0` ثابت می‌ماند.

## اجرای پروژه

1. Node.js نسخه 22 یا جدیدتر را نصب کنید.
2. در پوشه پروژه دستور `npm ci` را اجرا کنید.
3. برای توسعه از `npm run dev` استفاده کنید.
4. برای خروجی نهایی دستور `npm run build` را اجرا کنید.

## مسیرها

- `/` لندینگ معرفی محصول
- `/demo/commerce` داشبورد تجارت
- `/demo/analytics` تحلیل داده
- `/demo/projects` مدیریت پروژه‌ها
- `/demo/finance` امور مالی
- `/demo/crm` مدیریت مشتریان
- `/demo/academy` آکادمی آنلاین
- `/demo/calendar` تقویم فارسی
- `/demo/inbox` پیام‌ها و پشتیبانی
- `/demo/components` کتابخانه کامپوننت‌ها
- `/demo/settings` تنظیمات حساب

## شخصی‌سازی

رنگ‌ها، سطوح، کنتراست و فاصله‌ها در فایل‌های `app/globals.css` و `app/demo/[slug]/dashboard.css` تعریف شده‌اند. رنگ اصلی برند `#7367F0` است. همه صفحات از ویژگی `dir="rtl"` و تایپوگرافی فارسی استفاده می‌کنند.

## بسته بازاریابی

فایل‌های کاور و اینفوگرافی در پوشه `marketing` قرار دارند. نسخه SVG برای ویرایش و نسخه PNG برای بارگذاری در صفحه محصول مناسب است.

## سیاست نسخه

نسخه لورانیک همیشه `1.0.0` باقی می‌ماند. هنگام اعمال تغییرات، مقدار `version` در `package.json` و `package-lock.json` افزایش داده نشود.
