# محتوای آماده صفحه محصول راست‌چین

## عنوان محصول

قالب لورانیک؛ پنل مدیریت حرفه‌ای فارسی و کاملاً راست‌چین

## معرفی کوتاه

لورانیک یک پنل مدیریت مدرن، سریع و توسعه‌پذیر برای ساخت داشبوردهای فروشگاهی، تحلیلی، مالی، CRM، آموزشی و سازمانی است. تمام جزئیات رابط کاربری از ابتدا برای زبان فارسی، جهت RTL و نیازهای محصولات ایرانی طراحی شده‌اند.

## امکانات شاخص

- طراحی کاملاً راست‌چین و فارسی
- ده فضای کاری و دموی قابل پیمایش
- داشبورد تجارت و تحلیل داده با نمودارهای تعاملی
- مدیریت پروژه به سبک برد کاری
- صفحات مالی، CRM، آکادمی، پیام‌ها و تنظیمات
- تقویم فارسی و کتابخانه کامپوننت‌ها
- حالت روشن و تیره
- واکنش‌گرایی کامل برای موبایل، تبلت و دسکتاپ
- تایپوگرافی فارسی و رنگ‌بندی قابل شخصی‌سازی
- توسعه با React، Next.js و TypeScript
- مستندات نصب و شخصی‌سازی فارسی
- نسخه ثابت 1.0.0

## نیازمندی‌ها

- Node.js 22 یا جدیدتر
- آشنایی پایه با React و Next.js برای توسعه سفارشی

## برچسب‌های پیشنهادی

`پنل مدیریت`، `داشبورد فارسی`، `قالب RTL`، `Next.js`، `React`، `TypeScript`، `پنل فروشگاهی`، `CRM`، `داشبورد مالی`، `قالب مدیریتی`

## متن پشتیبانی

خریداران محصول به راهنمای نصب فارسی و پشتیبانی رفع اشکال دسترسی خواهند داشت. جزئیات مدت و سطح پشتیبانی هنگام ثبت محصول، مطابق پلن فروشنده در راست‌چین درج شود.

## تصاویر پیشنهادی برای بارگذاری

1. `marketing/cover.png` به‌عنوان کاور اصلی
2. `marketing/infographic.png` به‌عنوان معرفی بلند امکانات
3. اسکرین‌شات لندینگ
4. اسکرین‌شات داشبورد تجارت
5. اسکرین‌شات تحلیل داده
6. اسکرین‌شات برد پروژه و حالت تیره

## نکته انتشار

پس از ساخته‌شدن صفحه محصول در راست‌چین، نشانی واقعی خرید را در دکمه‌های فراخوان لندینگ جایگزین کنید. این لینک پیش از ایجاد صفحه محصول وجود ندارد و مانع بارگذاری بسته اولیه نیست.
