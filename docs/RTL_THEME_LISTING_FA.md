# برگه آماده‌سازی صفحه محصول راست‌چین — غیرقابل ارسال مستقیم

> این فایل **متن نهایی صفحه فروش نیست**. مطابق مرجع رسمی ثبت‌شده پروژه، متن نهایی محصول برای راست‌چین نباید با هوش مصنوعی نوشته شود. این برگه فقط اطلاعات فنی اثبات‌شده را برای نویسنده انسانی جمع می‌کند.

## اطلاعات فنی قابل استناد

- نام محصول: لورانیک ادمین / Loraniq Admin
- نسخه فعلی: `1.0.0`
- نوع محصول: قالب رابط مدیریتی React / Next.js
- زبان و جهت: فارسی و RTL
- مسیرهای دموی فعلی: ۱۰ فضای کاری تعاملی
- فناوری‌های ثبت‌شده: React 19، Next.js 16، TypeScript 5، Vinext، Recharts
- پیش‌نیاز Node.js: نسخه `22.13.0` یا جدیدتر
- حالت‌های ظاهری قابل مشاهده: روشن و تیره
- راهنمای فارسی مشتری: `docs/CUSTOMER_README_FA.md`

## ساختار الزامی برای نویسنده انسانی

### معرفی محصول

نویسنده انسانی باید **دقیقاً ۲ خط** بنویسد و فقط ماهیت محصول و کاربرد آن را توضیح دهد.

### ۵ ویژگی اصلی

نویسنده انسانی باید **دقیقاً ۵ ویژگی اصلی** را انتخاب کند و هر ویژگی را در یک خط مستقل بنویسد. فقط از قابلیت‌هایی استفاده شود که در Build و دمو قابل اثبات‌اند.

### فهرست کامل ویژگی‌ها

فقط عنوان ویژگی‌های واقعی نوشته شود؛ توضیح اضافه کنار هر مورد قرار نگیرد.

## دارایی‌های تصویری

- کاور نهایی: باید توسط طراح انسانی و مطابق قوانین جاری راست‌چین آماده شود.
- اینفوگرافیک نهایی: عرض ۹۶۰px، حجم کمتر از ۱MB و با منشأ انسانی قابل‌تأیید.
- اسکرین‌شات‌های CI در GitHub Actions فقط مدرک QA هستند و قبل از استفاده تبلیغاتی باید با قوانین جاری مارکت تطبیق داده شوند.

## مواردی که نباید ادعا شوند مگر دوباره اثبات شوند

- تعداد صفحه بیشتر از آنچه در نسخه فعلی واقعاً وجود دارد
- تعداد دمو بیشتر از ۱۰ مسیر فعلی
- امتیاز، رضایت، فروش، سرعت یا آمار کاربران بدون داده واقعی
- Backend، احراز هویت سازمانی یا API آماده؛ محصول فعلی یک قالب Front-end/React است
- سازگاری یا لایسنس فنی‌ای که هنوز روش رسمی آن برای این نوع محصول تأیید نشده باشد

## Gate باقی‌مانده قبل از ارسال

متن انسانی نهایی، کاور/اینفوگرافیک انسانی، لینک پیش‌نمایش عمومی واقعی، وضعیت لایسنس سازگار با راست‌چین و اطلاعات فروشنده/پشتیبانی باید در پنل فروشندگان نهایی شوند. وضعیت فنی Build و بسته‌بندی از Workflow مرجع خوانده شود.
