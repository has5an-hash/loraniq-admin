# داده‌های آماده ثبت محصول لورانیک در راست‌چین

> این سند **متن نهایی تبلیغاتی نیست**. فقط داده‌های فنی اثبات‌شده را برای ثبت محصول و نویسنده/طراح انسانی جمع می‌کند.

## هویت محصول

- نام فارسی: لورانیک ادمین
- نام انگلیسی: Loraniq Admin
- نسخه: `1.0.0`
- نوع محصول: قالب رابط کاربری پنل مدیریت React / Next.js
- دسته پیشنهادی بر پایه نمونه‌های جاری مارکت: قالب مدیریت HTML
- زبان و جهت: فارسی، RTL

- ۱۰ فضای کاری/دموی تعاملی
- داشبورد تجارت

- امور مالی
- CRM
- آکادمی

- کتابخانه کامپوننت‌ها
- تنظیمات حساب

- Responsive موبایل و دسکتاپ
- رابط فارسی و RTL

## فایل محصول

نام فایل تجاری تولیدشده توسط CI:

`Loraniq-Admin-RTLTheme-1.0.0.zip`

فایل معتبر باید از Artifact آخرین Release QA سبز گرفته شود؛ ZIPهای قدیمی موجود در تاریخچه مرجع ارسال نیستند.

## شواهد QA

QA خودکار شامل نصب تمیز، audit وابستگی production، lint، TypeScript، Release Gate، Build، اجرای Preview، تست HTTP تمام مسیرها، Screenshot دسکتاپ/موبایل، Overflow Gate، ساخت ZIP و Restore-test خود ZIP است.

Interaction QA نیز Dark/Light، جستجو، منوی موبایل، HTTP resource errors، page errors و overflow را روی هر ۱۰ دمو کنترل می‌کند.
