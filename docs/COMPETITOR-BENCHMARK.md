# Competitor Benchmark — Initial

Date checked: 2026-09-17

## Metronic

Current official positioning emphasizes Tailwind CSS 4, React 19, Next.js 16, TypeScript 5, Lucide, Radix/Base UI/shadcn, ten full demos, numerous layout starters, and broad app/page coverage. Its strongest lesson for Loraniq is system depth: reusable primitives, multiple layout modes, clear starter kits and production-scale coverage.

## Vuexy

Current discoverable official materials continue to emphasize carefully crafted admin UX, customization, layout structure, app-ready architecture and multiple framework implementations. Its strongest lesson for Loraniq is polish: clean hierarchy, comfortable information density, soft card treatment and easy-to-scan data surfaces.

## Loraniq independent response

- Keep Vuexy-like visual calm without copying its layout, assets or code.
- Pursue Metronic-like structural breadth through feature-based composition and documented tokens.
- Differentiate with Persian-first copy rhythm, true RTL/LTR runtime behavior, semantic color discipline, mobile table alternatives and regionally realistic data.
- Avoid unverifiable feature-count claims; only implemented and tested surfaces will be marketed.
