# Loraniq Admin — لورانیک ادمین

لورانیک ادمین یک قالب پنل مدیریت فارسی و RTL بر پایه React، Next.js، TypeScript و Vinext است. مرجع فعلی توسعه و انتشار همین مخزن است و نسخه محصول برای انتشار اولیه روی `1.0.0` قرار دارد.

## پیش‌نیاز

- Node.js `>=22.13.0`
- npm همراه Node.js

## اجرا

```bash
npm ci
npm run dev
```

پیش‌نمایش توسعه به‌صورت پیش‌فرض روی پورت `5173` اجرا می‌شود.

## کنترل کیفیت

```bash
npm run lint
npm run typecheck
npm run check:release
npm run build
```

یا همه مراحل اصلی را یکجا اجرا کنید:

```bash
npm run check
```

## مسیرهای دموی تأییدشده

- `/demo/commerce` — تجارت
- `/demo/analytics` — تحلیل داده
- `/demo/projects` — مدیریت پروژه
- `/demo/finance` — امور مالی
- `/demo/crm` — مدیریت مشتریان
- `/demo/academy` — آکادمی
- `/demo/calendar` — تقویم
- `/demo/inbox` — پیام‌ها
- `/demo/components` — کتابخانه کامپوننت‌ها
- `/demo/settings` — تنظیمات

در مجموع ۱۰ فضای کاری/مسیر دموی تعاملی در نسخه فعلی وجود دارد. هیچ عدد یا قابلیت دیگری نباید در صفحه فروش ادعا شود مگر اینکه در سورس و QA همان نسخه اثبات شده باشد.

## ساختار مهم

- `app/` — لندینگ و دموهای محصول
- `components/` — کامپوننت‌های مشترک
- `docs/README_FA.md` — راهنمای فارسی مشتری
- `docs/RELEASE_CHECKLIST_FA.md` — Gate انتشار
- `scripts/release-check.mjs` — کنترل قطعی ادعاها و فایل‌های حساس
- `release/` — خروجی‌های قدیمی/مرجع؛ خروجی معتبر جدید باید از GitHub Actions ساخته شود
- `marketing/` — دارایی‌های قدیمی بازاریابی؛ برای ارسال به راست‌چین فقط دارایی تأییدشده طبق وضعیت انتشار استفاده شود

## انتشار

Workflow مخزن مراحل زیر را اجرا می‌کند:

1. نصب قفل‌شده وابستگی‌ها با `npm ci`
2. ESLint
3. TypeScript type-check
4. Release gate
5. Build production
6. اجرای Preview ساخته‌شده و Smoke Test مسیرهای اصلی
7. ساخت بسته تمیز سورس
8. تولید فهرست SHA-256 و اطلاعات ساخت
9. بارگذاری Artifactهای خروجی

تا زمانی که Workflow سبز نشده و موارد انسانی/مارکت‌پلیس در `docs/RELEASE_CHECKLIST_FA.md` بسته نشده‌اند، محصول «آماده انتشار قطعی» محسوب نمی‌شود.

## قوانین انتشار راست‌چین

برای دارایی‌های صفحه محصول و متن فروش، از استانداردهای جاری راست‌چین پیروی شود. فایل‌های قدیمی `marketing/` به‌صورت خودکار به معنی تأیید برای بارگذاری در مارکت نیستند. محتوای نهایی صفحه محصول و دارایی‌های بصری باید قبل از ارسال از نظر قوانین فعلی راست‌چین بازبینی شوند.

## مجوزها

جزئیات در `LICENSES.md` ثبت می‌شود. کتابخانه‌های شخص ثالث تحت مجوز خودشان باقی می‌مانند و نباید ادعای مالکیت روی آن‌ها شود.
