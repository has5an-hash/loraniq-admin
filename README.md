# Loraniq Admin / لورانیک ادمین

Premium Persian, RTL-first admin template built with React, TypeScript and Tailwind CSS.

## Development

```bash
pnpm install
pnpm dev
```

## Quality commands

```bash
pnpm lint
pnpm build
```

## Product principles

- Persian and RTL are first-class, while English/LTR remains fully supported.
- Light and dark themes are separately designed.
- Components use semantic colors, accessible focus states and reduced-motion behavior.
- Marketplace claims must match tested release functionality.

See `docs/PROJECT-AUDIT.md`, `docs/DESIGN-SYSTEM.md`, and `docs/PROJECT-STATUS.md` for the working baseline.
